# 成果与交接

## 完成内容

列出实现的行为和对应文件，不要只写“已完成”。

## 验证

记录命令、结果和未覆盖的边界；如验证受阻，写出事实和所需条件。

## 遗留与下一步

记录未完成项、阻塞、设计约束和下一位 agent 需要的最小背景。

## 当前工作区

说明已修改/新增文件、Git 分支和已产生的提交。不要复制令牌、完整对话或无关私密内容。

使用方式：`python -S agentctl.py --profile YOUR_PROFILE submit TASK_ID --file examples/handoff-template.md`。填写真实内容后再提交；该命令进入 review，管理员验收后才进入 done。
